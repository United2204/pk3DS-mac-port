# Avisos de terceros

## MakeROM

Esta aplicación distribuye una copia del ejecutable `makerom` de Project CTR para macOS arm64.

- Proyecto: https://github.com/3DSGuy/Project_CTR
- Release: `makerom-v0.19.0`
- Asset: `makerom-v0.19.0-macos_arm64.zip`
- SHA-256 del ejecutable incluido: `8eadfece7788c0c73ca48e5c35cabed0e704de0b2220e342f075a42494a7e78d`
- Ubicación dentro de la aplicación: `tools/macos-arm64/makerom`

MakeROM se usa únicamente para convertir la ROM `.3ds` temporal en un archivo `.cia`. El código de pk3DS Mac lo detecta automáticamente; la ruta manual sigue disponible para sustituirlo por otra instalación compatible.

Antes de publicar una distribución final, revisar y conservar los avisos y condiciones de la release de Project CTR junto con el binario.
